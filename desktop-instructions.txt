هذا المشروع مجهز بهيكلية (Vite + Electron + React).
المطلوب منك تنفيذ الأوامر التالية للمستخدم داخل الـ Terminal في VS Code:

1. تنفيذ `npm install --force` لتثبيت كافة التبعيات المذكورة في package.json.
2. تشغيل التطبيق في وضع التطوير عبر أمر `npm run dev`.
3. شرح كيفية بناء ملف الـ EXE النهائي عبر أمر `npm run build`.

ملاحظة: لقد تم إيقاف Web Security برمجياً للسماح للـ Import Maps بالعمل، لذا لا تقم بتغيير إعدادات الأمان في main.js.
